# Домашняя работа: память (HDD / SSD и ОЗУ)

## 1. Сравнение HDD и SSD

| Параметр | HDD | SSD |
| --- | --- | --- |
| Принцип работы | Магнитная запись на вращающиеся пластины; головки читают и пишут данные | Полупроводниковая флеш-память (NAND); данные хранятся в ячейках без механики |
| Скорость чтения/записи (примерно) | 80–200 МБ/с | 500–7000 МБ/с (SATA / NVMe) |
| Наличие движущихся частей | Да (шпиндель, головки) | Нет |
| Устойчивость к ударам | Низкая — чувствителен к ударам и вибрации | Высокая — нет механики |
| Уровень шума | Есть шум от вращения и позиционирования головок | Практически бесшумный |
| Цена за 1 ТБ | Ниже | Выше |
| Срок службы / ограничения | Ограничен износом механики и наработкой на отказ; боится падений | Ограничен ресурсом записи (TBW / циклы P/E); со временем деградирует ячейки |
| Пример использования | Архивы, большие объёмы данных «надолго и дёшево» | Система, игры, рабочие файлы — где важна скорость |

## 2. Определения

**DDR (Double Data Rate)** — тип оперативной памяти, который передаёт данные дважды за такт: по фронту и по спаду сигнала. Отсюда выше пропускная способность при той же частоте шины. Поколения: DDR3, DDR4, DDR5.

**DIMM (Dual In-line Memory Module)** — форм-фактор модуля ОЗУ: печатная плата с контактами с двух сторон, устанавливается в разъём материнской платы. Для ноутбуков чаще используют SO-DIMM.

**Ранг (rank)** — набор чипов на модуле, к которому контроллер памяти обращается как к одной «полосе» данных ширины шины (обычно 64 бит). Модуль может быть single-/dual-/quad-rank; больше рангов — больше ёмкость при той же организации чипов, но иногда чуть выше задержки.

**CAS Latency (CL)** — число тактов от подачи адреса столбца до появления первых данных. Меньший CL при той же частоте означает более быстрый отклик памяти.

**Тайминги** — набор задержек модуля ОЗУ в тактах (например `CL-tRCD-tRP-tRAS`, вроде `16-18-18-36`). Они описывают, сколько тактов нужно на разные этапы доступа к ячейкам DRAM.

**Двухканальный режим** — установка модулей парами в соответствующие слоты, чтобы контроллер читал/писал по двум каналам сразу. Итог: выше суммарная пропускная способность ОЗУ (часто заметно в играх и тяжёлых задачах).
